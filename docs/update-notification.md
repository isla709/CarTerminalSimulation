# 新版本提示气泡

自动检查发现可升级版本时，在主窗口设置齿轮下方显示轻量气泡，包括版本号、“不再提示”和“查看详情”。不为同版本切换、降级或空列表显示气泡。同一版本在一次程序运行中只提示一次，手动版本管理已经看到的版本不再额外弹气泡。

气泡非模态，不自动升级，不自动打开升级对话框，也不抢焦点。点击外部、关闭按钮或 Escape 可暂时关闭；程序移动 / 调整窗口时气泡仍跟随设置图标。程序未激活或已最小化时延后显示，不在其他应用上主动提示。系统禁用窗口动画时不播放淡入动画。

“不再提示”关闭所有新版本气泡，选择保存在 `config.json` 的 `ShowUpdateNotifications`（旧配置默认 `true`）。可在“设置 → 关于”重新勾选“显示新版本提示气泡”。关闭气泡不关闭自动检查，也不隐藏手动版本管理或可用版本。

“查看详情”打开设置的“关于”页并进入版本管理，优先复用刚检查到的版本列表，不重复请求网络。选择版本、选择下载源并确认后才启动更新器。版本线、测试序列及兼容级别限制沿用现有更新服务，不因气泡而放宽。

自动检查开关及检查间隔仍由现有 `update-sources.json` 控制。
