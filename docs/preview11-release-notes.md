# Preview11 更新介绍

Preview11 聚焦安装与跨版本更新的稳定性，同时完善轨迹模拟和系统日志。

## 安装与更新

- 首次引入完整安装向导，支持目录选择、桌面 / 开始菜单快捷方式、原目录修复及卸载；默认安装到 Program Files，首次准备应用目录时请求一次管理员授权，不要求预装 .NET。
- 主程序与更新引擎共用一份离线 .NET 8 运行时，减少安装包重复内容；新安装默认使用独立安装包。
- 同一个安装 EXE 手动运行是安装程序，更新器调用时只准备载荷，不再弹出第二个安装向导。
- 安装包保留旧 ZIP 读取兼容性，新更新系统自动适配历史 ZIP 与新安装 EXE。
- 持久原生更新入口、隔离更新引擎和私有运行时缓存，不随主程序降级。更新引擎复用包内运行时，并在更新期间复制到临时工作区；支持同版本线、兼容级别允许范围内的新旧版本往返。
- 写前日志、备份、启动验证和故障回滚；安装、更新、卸载保护配置、工作区及插件数据。
- 更新及安装界面采用现代卡片布局、平滑动效；更新图标保持向上箭头静止，仅外围圆环旋转。

## 轨迹模拟

- “地图选点”正式更名“轨迹模拟”，old / new 两套地图保持独立。
- 随机交通系统由简化测试事件升级为 14 类分阶段情景：单轮 / 多轮红灯、无保护左转、人行横道礼让、走走停停、幽灵堵车、慢车跟行、邻车切入、合流、临时占道、施工、应急车辆避让、减速带及可选铁路道口。
- 逐类配置开关、触发概率、平均机会间隔、时间范围，以及适用的轮数和缓行速度；提供畅通、日常通勤和高峰拥堵配置。
- 停车后才计等待时间，多轮队列真实前移再停车；手动接管取消情景。所有情景均为虚拟速度行为，不代表实时交通识别。

## 日志与文案

- “通信日志”升级为“系统日志”，通信、系统、插件分类可单独或组合筛选，隐藏记录仍保留。
- “终端心跳保活”简化为“终端心跳”。
