# Preview9：双地图方案与导航式轨迹模拟

版本：`preview9-build.20261008.1`  
发布通道：`preview` · 版本线：`main` · 兼容级别：`1`  
平台：Windows x64

## 版本简介

Preview9 将地图选点升级为导航式轨迹模拟工作区：加入腾讯地图 2D/3D 视图、详细地点搜索、起终点选择和多条驾车路线对比，同时完整保留原地图方案。两套地图通过 `config.json` 中的 `MapProvider` 字段选择，兼顾新的导航体验与原有使用习惯。地图外观、车辆航向、坐标系处理和服务错误提示也得到完善。

## 本次更新

### 导航式地图工作区

- 新增基于腾讯地图 JavaScript API GL 的地图方案，采用浮动规划面板、路线候选卡片和地图状态提示。
- 支持 2D/3D 视图切换，并调整浮动工具位置，减少对地图原生视图控件的遮挡。
- 地点搜索显示名称、分类和地址，可将结果设为起点、终点，或直接定位查看。
- 支持地图点选起终点、交换起终点、重新规划，以及在服务返回的多条驾车路线之间选择。
- 路线候选展示距离、预计时间、红绿灯、费用和服务返回的路线标签，便于选择模拟路径。
- 保留自由绘制模式，可依次添加轨迹点、撤销和重新绘制；导航路线与自由绘制可自由选择。
- 车辆位置支持平滑过渡，修正车辆方向标记与航向角的对应关系。

### 完整保留两套地图方案

- `new`：新版腾讯地图方案，默认启用。
- `old`：原 Leaflet 地图方案，保留地点搜索、导航规划、自由绘制、地图滤镜和轨迹模拟。
- 两套地图各自初始化；新版初始化失败时不再自动切换旧版。
- 旧版地图不依赖腾讯地图 Key，也不调用腾讯 IP 定位接口。
- 两套方案的地图风格分别保存，避免切换方案时互相覆盖。
- 暂不在设置界面提供方案切换入口。关闭程序后编辑程序目录下的 `config.json`，修改 `MapProvider` 并重新启动即可生效。

```json
"MapProvider": "old"
```

恢复新版时改为 `"MapProvider": "new"`。字段缺失或值无效时使用新版。

### 地图设置与样式修正

- 新版地图的风格选项收敛为“腾讯默认”和当前 Key 已绑定的“墨渊（style1）”。
- 移除无法直接用于当前 Key 的公共展示页样式编号，旧版无效腾讯样式配置回退为默认。
- 原 Leaflet 地图继续保留自己的滤镜选项，并使用独立的 `LeafletMapStyle` 配置保存。
- 默认城市、网络定位与路线样式继续在地图中的独立设置卡片内管理。
- 腾讯服务调用在程序侧完成，并提供搜索/规划请求状态管理与错误反馈。
- 针对接口额度未分配等错误提供更明确的提示，帮助区分 Key 配额和一般网络故障。

### 延续 Preview8 的路线与更新能力

以下功能在 Preview8 中已提供，Preview9 继续保留：

- `.ctsroute` 路线保存与打开，保存路径、路线模式和坐标系；打开时按文件恢复坐标系。
- WGS-84、GCJ-02、BD-09 切换。已有点位可选择直接切换坐标解释，或转换坐标并保持实际地图位置。
- 路线模拟与 JT/T 808 上报采用当前选择的逻辑坐标系；地图底图展示所需转换在显示层处理。
- GitHub/GitCode 多源版本聚合、来源展示，以及下载前的连通性检测和推荐源选择。
- 用户自主选择升级、同序列切换或兼容版本回退；版本线隔离和不可逆兼容级别保护继续生效。
- 独立 `update.exe` 下载并校验 ZIP、备份替换、失败回滚，完成后自动启动主程序。
- HTTP 调试工作空间、结构化正文编辑、主题背景和原有 JT808/JT1078 功能继续保留。

## 升级与运行说明

- 本包为 Windows x64 自包含目录式发布。下载后解压整个 ZIP，运行 `TerminalSimulation.Wpf.exe`；请保留 `MapApp/`、`Plugins/`、`ffmpeg-native/` 等目录及 `update.exe`。
- 包内携带 .NET 8 运行时；地图仍需要 WebView2 运行时和网络连接。
- 更新包不携带个人 `config.json`、账号配置、HTTP 工作空间或本机缓存。应用内更新仅替换包内程序文件，保留原有用户数据。
- 从 main 线的兼容 Preview 版本可通过版本管理选择本版本；本版兼容级别仍为 1。
- 腾讯地图的在线搜索、规划和定位受服务可用性及 Key 配额影响；地图风格只显示当前绑定样式。
- FFmpeg 采用进程内原生模块并随包携带，无联网下载回退。
