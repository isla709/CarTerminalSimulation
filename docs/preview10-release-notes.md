# Preview10：真实驾驶模拟与地图交互完善

版本序列：`Preview10` / `preview10`；版本线：`main`；更新通道：`preview`；兼容级别：`1`。具体构建号以发布包和清单为准。

## 简短介绍

Preview10 新增真实驾驶轨迹模拟，支持车辆预设、平顺加减速、弯道处理、手动换挡与可选随机驾驶事件；同步完善 old/new 两套地图的搜索联想、单点选择、独立记录管理和轨迹去重。主程序与更新器采用统一风格的系统图标，修复启动封面圆角，并新增可关闭的新版本提示气泡。

## 详细更新

### 真实驾驶速度与车辆操作

- 保留固定速度模式，在模拟速度旁新增车辆设置入口，可切换真实驾驶速度模式。
- 可配置最大速度、期望平均速度、驾驶风格、加速能力、制动能力、变速箱和动力类型。
- 提供小型手动挡汽车、小型普通自动挡汽车、电动汽车、大型手动挡卡车 / 洒水车四种预设。
- 手动挡支持各挡齿比、主减速比、车轮半径、升降挡转速和换挡时间等参数；运行中可切换自动 / 手动操作，调节挡位、油门及刹车。
- 速度模型涵盖静止起步、平顺加减速、巡航波动、换挡动力中断与终点停车；空挡无驱动力，危险降挡转速会被拒绝。
- 左右转分别处理，连续同向折点合并判断弯道。提前减速入弯，从弯心开始加速出弯，接近 90° 的右转采用更低的弯心速度。
- 右下角状态面板展示坐标系、实际速度、期望 / 上限、挡位、转速、全程平均速度与操作状态；支持展开、收起及停止模拟。
- 路线推进、主界面速度和 JT/T 808 上报使用同一实际模拟速度；现有上报开关和间隔仍由用户控制。

### 可选随机驾驶事件

- 新增“启用随机驾驶事件”选项，默认关闭，仅在真实驾驶的自动操作中生效。
- 支持汇入口排队减速、短时加速汇入、右转礼让行人、超车加速通过和红灯等待等虚拟场景。
- 事件具有触发间隔、冷却及速度限制，不叠加执行；停车等待在实际停稳后才开始计时，手动接管立即取消事件。
- 状态面板明确展示模拟事件、执行阶段与倒计时。

这些事件是协议测试用的纵向速度变化，不代表真实交通 / 信号灯识别，也不生成横向变道轨迹。车辆预设为通用示例，期望平均速度是巡航目标，不保证全程平均值。模型不是实车标定或驾驶教学系统。详见 [真实驾驶轨迹模拟](vehicle-simulation.md)。

### 两套地图的交互与记录

- `old/new` 均增加单点选择，与导航路线、自由绘制自由切换；单点模式始终仅保留一个点。
- 控件、面板、模式切换、联想列表与卡片弹窗加入现代化过渡动画，统一定位 / 设置 / 收起按钮图标和布局，标题简化为“地图与轨迹”。
- 搜索增加输入联想、中文输入法处理、过期响应保护，以及上下键、Enter、Escape 操作。
- 搜索记录支持单条删除、管理与清空；轨迹库支持自动 / 手动记录、恢复、重命名、删除与清空。
- 轨迹按选点模式和有序点去重，不因速度、车辆配置或名称不同重复保存。同一路线更新为最新参数，自动记录保留用户重命名。
- 等价坐标转换后的路线可在 0.5 米逐点容差内识别为重复；换算仅用于比较，不改变保存的原始坐标系。反向路线、不同模式和实际位置不同的路线不合并。
- 首次加载既有重复项时保留最新项，并生成去重前的独立备份。
- `old` 使用独立 Leaflet 前端与随包提供的固定版本依赖，搜索 / 联想使用 Photon；旧方案保持二维，不显示不支持的 3D 控件。
- 修复搜索框内部矩形蓝色焦点框；将 `NARROW`、`LEAST_LIGHT` 等路线标签转换为中文，合并重复标签并隐藏未知枚举。
- 修复原生图片 / 文本拖放造成的禁止光标，避免拖图结束误选点；模拟时手动拖图暂停自动跟随，可通过定位按钮恢复。

两套地图仍通过 `config.json.MapProvider` 的 `old/new` 手动切换，搜索记录、轨迹记录与车辆设置分别保存在 `Workspaces/Map/old/` 和 `Workspaces/Map/new/`，互不混用。详见 [地图操作增强](map-ui-preview10.md)。

### 系统图标与启动封面

- 主程序和独立 `update.exe` 新增简约、直观的图标，覆盖 EXE 资源、窗口标题栏、任务栏及系统进程展示等入口。
- ICO 包含 16 至 256 像素的十种尺寸；主程序与更新器分别设置稳定 Windows 应用标识，避免版本或临时路径造成窗口分组变化。
- 修复启动图片四角未随外框圆角裁剪的问题，对图片及覆盖内容进行实际圆角裁剪，适配窗口尺寸变化。

### 安静、可关闭的更新提醒

- 修复 Preview9 起自包含更新器临时启动时遗漏运行时的问题：按依赖清单复制完整更新器运行环境，不再误报需要安装 .NET Desktop Runtime，且不复制主程序或用户数据。
- 统一主程序与更新器的 JSON 依赖版本，补全 `System.IO.Pipelines` 等传递依赖，并记录启动器阶段错误日志，避免共享安装目录中的版本冲突。
- 修复从自包含版本切换到 Preview8 等框架依赖版本时旧运行时残留的问题，清理范围仅限目标包不再使用的运行时文件，保留备份并支持失败回滚。
- 调整独立更新窗口布局，避免下载 / 安装状态被按钮挤压裁切；长错误信息可滚动查看，统一进度条与按钮样式。
- 检测到更高兼容版本时，在设置图标下方显示非模态气泡，不强制升级、不自动安装。
- “查看详情”跳转至设置中的关于页和版本管理，仍需用户选择版本、来源并确认。
- “不再提示”持久关闭气泡，可在关于页重新开启，不影响手动版本管理和更新检查。
- 同一版本每次运行最多自动提示一次；后台或最小化时延迟到窗口激活，主动打开版本管理后不重复提示该候选。
- 延续同版本切换、升级优先、版本线 / 测试序列隔离、兼容级别保护和多源下载选择机制。

详见 [新版本提示气泡](update-notification.md) 和 [自动更新发布规范](automatic-updates.md)。

### 内部插件与公开构建

- `TerminalSimulation.Plugins.XunjieCloud` 从当前 Git 版本移除并停止跟踪，本地源码保留。
- 主程序、测试和发布流程不再强制依赖内部插件，缺少该目录也可构建；本地存在时仍可选择包含。
- 公开发布必须显式设置 `IncludeXunjieCloudPlugin=false`，使用新的输出目录避免旧二进制残留。

此次移除不重写旧 Git 历史。详见 [内部插件约定](internal-plugins.md)。

## 延续能力与兼容说明

- 腾讯地图 GL、2D / 3D、多路线导航、地图风格和多源更新属于此前版本能力，本次在其基础上增强交互，不作为新引入的地图引擎。
- 轨迹、模拟与上报始终采用用户所选坐标系；打开路线文件恢复文件坐标系，切换时仍可选择直接解释或转换以保持地图位置。
- `.ctsroute` 继续兼容既有文件；新增车辆配置为可选内容，无车辆配置的旧文件按固定速度恢复。轨迹库删除不删除已导出的路线文件。
- 搜索与导航依赖对应在线服务，公共服务可用性与 API 配额不由应用保证。
- 此文档不代表已经生成或上传 Preview10 发布包。发布时须统一程序、ZIP 和清单中的确定构建号，并按项目规则输出至 `artifacts/publish/`。
