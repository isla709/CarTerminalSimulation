# 真实驾驶轨迹模拟

`old` 和 `new` 地图均支持。在原有“模拟速度”右侧点击车辆设置入口，启用“真实驾驶速度”。关闭后仍使用固定速度模式。

## 设置

- 最大速度：硬上限，单位 km/h。
- 期望平均速度：期望巡航水平，不是强制保证的全程平均值。起步、弯道、换挡、手动操作及终点停车会降低全程平均速度。
- 驾驶风格：温和、普通、积极。影响加减速平顺程度、弯道速度及巡航波动。
- 汽车加速能力、最大刹车减速度：单位 m/s²，限制动力及制动能力。
- 变速箱：手动、普通自动、CVT、双离合、单速减速器。
- 动力：汽油、柴油、纯电、混合动力。柴油采用更平顺的加速度变化，电动包含随速度变化的动力与轻度滑行回收，混动包含简化的动力辅助。CVT 转速采用连续变速的近似巡航模型，双离合的动力中断时间较短。
- 传动参数：各挡位齿比、主减速比、车轮半径、怠速及红线、自动升降挡转速、换挡动力中断时间。齿比须从 1 挡起逐挡递减，最多 12 挡。

提供小型手动挡汽车、小型普通自动挡汽车、电动汽车、大型手动挡卡车 / 洒水车四种预设。预设参数是通用示例，并非具体品牌车型的实测数据。

## 运行和手动操作

真实驾驶从静止起步，结合前方轨迹的转向角和近似弯道半径提前减速，从弯心开始平顺加速出弯，接近终点平顺停车。左右转分别识别，接近 90° 的右转采用更低的弯心速度；连续同向的小折点合并成一个弯道，减少导航折线造成的反复刹车。减速包络预留控制反应距离，不再在弯后固定保持一段低速。巡航加入连续的小幅速度波动。

## 随机驾驶事件

在车辆设置卡片勾选“启用随机驾驶事件”，默认关闭。仅在真实驾驶的自动操作中生效；切到手动操作立即取消当前事件，不干预用户油门、刹车。选项随两套地图的独立车辆设置及轨迹文件保存。

- 汇入口减速排队：降至约 8–15 km/h 缓行，停稳后等待约 3–9 秒，再恢复驾驶。
- 短时加速汇入、超车加速通过：约 4–10 秒的速度提升，仍受最大速度、弯道速度和终点减速约束。只是纵向速度事件，不偏移保存的轨迹来虚构横向变道。
- 右转礼让行人：仅在前方可识别的右转处随机触发，在弯心前约 5 米的虚拟等待点停下，等待约 4–10 秒。
- 红灯等待：在较大转向处模拟路口停车，停稳后等待约 10–30 秒，再平顺起步。

首个事件在满足行驶条件后约 15–35 秒随机触发；事件结束后有约 25–65 秒的冷却，不同时叠加多个事件。低速起步、临近终点时不产生新事件，停车点不设置在路线终点之外。状态面板显示“模拟事件”、处理阶段和等待 / 持续时间；等待倒计时只在实际速度降至近零后减少。

这些都是协议测试用的虚拟场景，不是在线道路交通、行人或信号灯识别。路口位置仅由轨迹转向近似判断，没有真实信号灯数据时不会声称该处确有红灯。

地图右下角驾驶状态面板显示当前坐标系、实际速度、期望 / 上限、挡位、发动机或电机转速、全程平均、动力和变速箱、油门和刹车。小窗口默认收起详细区域，可手动展开。停止模拟入口始终保留。

手动挡默认由系统自动操作。切换“手动操作”后可选择 N 空挡或实际挡位、升降挡、调节油门开度和刹车力度，再随时恢复自动操作。空挡和换挡期间没有驱动动力；预计降挡转速超出红线时拒绝降挡并提示。手动操作允许偏离弯道建议速度，但仍受车辆最大速度、转速及动力能力约束；终点会结束轨迹。这适用于构造怠速、滑行、急刹等调试场景，不是驾驶教学或车辆安全控制。

## 上报、坐标和存储

模型每 50ms 左右积分速度，每 100ms 左右同步位置和驾驶状态。同一速度用于推进路线并更新主界面速度，JT/T 808 位置汇报读取该实际速度（协议精度 0.1 km/h）。汇报开关和汇报间隔仍由现有通信设置控制，不因启用车辆模型而自动打开汇报。原始轨迹、模拟和上报坐标系保持一致，不添加新的隐式坐标转换。

两套地图的车辆设置互相独立，保存在主程序目录：

```text
Workspaces/Map/old/vehicle.json
Workspaces/Map/new/vehicle.json
```

保存采用原子写入。轨迹库快照和 `.ctsroute` 文件会带上车辆设置，恢复轨迹时一并恢复。未包含车辆设置的旧轨迹按原有固定速度打开。运行中的挡位、油门和刹车指令不会存成下次自动执行的操作。

## 模型边界

这是面向协议测试的驾驶行为近似，不是经过车型标定的完整车辆物理系统。仅利用已有轨迹几何，随机事件须明确启用且标为模拟事件，不把它们当作真实路况；不计算真实离合器、发动机扭矩曲线、质量载荷、坡度和轮胎附着。路线的稀疏程度会影响弯道判断。小幅巡航波动采用可重复的平滑函数；随机事件测试可注入随机种子，便于回归。
