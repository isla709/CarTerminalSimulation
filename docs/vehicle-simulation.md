# 真实驾驶轨迹模拟

`old` 和 `new` 地图均支持。在原有“模拟速度”右侧点击车辆设置入口，启用“真实驾驶速度”。关闭后仍使用固定速度模式。

## 设置

- 最大速度：硬上限，单位 km/h。
- 期望平均速度：期望巡航水平，不是强制保证的全程平均值。起步、弯道、换挡、手动操作及终点停车会降低全程平均速度。
- 驾驶风格：温和、普通、积极。影响加减速平顺程度、弯道速度及巡航波动。
- 汽车加速能力、最大刹车减速度：单位 m/s²，限制动力及制动能力。
- 变速箱：手动、普通自动、CVT、双离合、单速减速器。
- 动力：汽油、柴油、纯电、混合动力。柴油采用更平顺的加速度变化，电动包含随速度变化的动力与轻度滑行回收，混动包含简化的动力辅助。CVT 转速采用连续变速的近似巡航模型，双离合的动力中断时间较短。
- 传动参数：各挡位齿比、主减速比、车轮半径、怠速及红线、自动升降挡转速、换挡动力中断时间。齿比须从 1 挡起逐挡递减，最多 12 挡。

提供小型手动挡汽车、小型普通自动挡汽车、电动汽车、大型手动挡卡车 / 洒水车四种预设。预设参数是通用示例，并非具体品牌车型的实测数据。

## 运行和手动操作

真实驾驶从静止起步，结合前方轨迹的转向角和近似弯道半径提前减速，从弯心开始平顺加速出弯，接近终点平顺停车。左右转分别识别，接近 90° 的右转采用更低的弯心速度；连续同向的小折点合并成一个弯道，减少导航折线造成的反复刹车。减速包络预留控制反应距离，不再在弯后固定保持一段低速。巡航加入连续的小幅速度波动。

## 随机交通情景（Preview11）

原来五种一次性测试事件已替换为分阶段情景模型。在车辆设置卡片勾选“启用随机交通情景”，总开关默认关闭。仅在真实驾驶的自动操作中生效；切到手动操作立即取消当前情景，不干预用户油门、刹车，恢复自动操作也不会接续之前的停车阶段。

### 情景种类

| 类别 | 情景 | 驾驶过程 |
| --- | --- | --- |
| 路口 | 一轮红灯 | 提前制动、停稳等待、绿灯起步反应、平顺放行 |
| 路口 | 多轮红灯排队 | 红灯停车、绿灯队列前移、再次停车，经过 2–4 轮后通过（默认轮数） |
| 路口 | 无保护左转 | 仅在左转前等对向车流间隙，缓慢通过 |
| 路口 | 人行横道礼让 | 接近虚拟过街点，停车等行人，观察后起步 |
| 车流 | 走走停停 | 反复停车、前车起步反应、蠕行推进，最后恢复车流 |
| 车流 | 幽灵堵车 | 连续车流压缩波和短暂恢复，部分压缩波会完全停车，最后消散 |
| 车流 | 慢车跟行 | 低速跟随，目标速度连续小幅波动，随后恢复 |
| 车流 | 邻车切入 | 收油减速、拉开车距，再逐渐恢复 |
| 车流 | 汇入口交替通行 | 接近合流队尾、停车让行、低速前移，多次后汇入 |
| 干扰 | 公交停靠 / 临时占道 | 等待前方车道解除占用，再缓慢通行 |
| 干扰 | 施工窄道 | 入口停车等候交替放行，低速通过施工段 |
| 干扰 | 应急车辆避让 | 平顺减速停车、避让、观察后恢复 |
| 干扰 | 减速带 / 破损路面 | 以空间距离提前减速，低速通过一小段，再恢复 |
| 干扰 | 铁路道口 | 停车等栏杆开启，低速通过；默认关闭，需自行启用 |

所有情景只改变所选轨迹上的纵向速度，不虚构横向变道、绕行或道路实体。除真实驾驶本身的小幅巡航波动之外，不再使用旧的“随机加速汇入 / 超车加速”测试事件。

### 每类情景可配置

- 独立开关，以及每次机会的触发概率 `0–100%`；`0%` 不触发。
- 平均机会间隔 `5–3600 秒`：以**空闲、满足该事件道路条件、速度至少 8 km/h** 的行驶时间计算独立随机机会时钟，时间分布是指数分布，不是固定周期。每次机会再按概率抽签；未命中同样开始新的机会间隔。
- 最短 / 最长阶段时间 `1–180 秒`：停车类为每轮**停稳后**等待时长，慢车/拥堵波等为每段受限时长。起步反应、队列前移、恢复另计，多轮事件的总时间会更长。
- 多轮情景可设最少 / 最多轮数 `1–6`；有缓行阶段的情景可设缓行速度 `2–60 km/h`，仍受车辆、道路弯道及终点速度包络限制。

例如机会间隔 120 秒、概率 50%，表示在持续满足条件且没有其他事件的理想情况下，平均约 240 秒命中一次；不是保证每四分钟发生，也不是每秒有 50% 概率。

### 全局控制与道路条件

- 首次触发前及每个事件结束后保留最小间隔（可设 `5–600 秒`）；结束后的实际冷却在最小间隔至其 1.5 倍之间随机。冷却只在有足够剩余路程且速度达到条件时消耗。
- 一次只执行一个情景，其他事件不会积压；结束后重置机会时钟，避免刚结束就连发另一事件。
- 新情景避开弯心、低速起步和临近终点；停车点预留制动与反应距离、队列推进和终点余量。多轮信号队列逐步接近路口，不在每次红灯时越过路口。
- 红灯可安排在已有轨迹的较大转向前。也可开启“允许在直路布置虚拟信号路口”（默认开），最小间距可设 `100–5000 米`，默认 450 米，直线轨迹也可模拟路口。关闭后只用几何可识别的转向。无保护左转只安排在左转前。
- 三个快速配置：畅通道路减少拥堵情景与频次；日常通勤恢复交通默认配置；高峰拥堵提高排队、拥堵波等机会与概率。切换车辆预设不会覆盖单独调整的交通配置。快速交通配置会覆盖当前交通配置，保存前可继续修改或取消。

驾驶状态卡显示“模拟情景”、具体阶段、当前轮次 / 总轮数和阶段剩余时间；队列前移阶段以真实位移推进，不显示虚假的固定倒计时。速度由原有动力 / 制动 / 平顺控制积分产生，同步用于路径移动和协议上报，绝不瞬移、强制写速度或绕过最大速度。设置在下一次开始模拟生效，模拟中保持手动接管与停止操作可用。

这些都是协议测试用的**虚拟交通场景**，不是在线路况、行人或信号灯识别。当前仅有路线几何，没有真实车道、路口、信号相位、施工、铁路等数据；对应事件只在保存的路径上构造速度行为，不表示地图上该处实际存在该设施或状况。道路条件不满足时，即使 100% 概率也不保证触发。

地图右下角驾驶状态面板显示当前坐标系、实际速度、期望 / 上限、挡位、发动机或电机转速、全程平均、动力和变速箱、油门和刹车。小窗口默认收起详细区域，可手动展开。停止模拟入口始终保留。

手动挡默认由系统自动操作。切换“手动操作”后可选择 N 空挡或实际挡位、升降挡、调节油门开度和刹车力度，再随时恢复自动操作。空挡和换挡期间没有驱动动力；预计降挡转速超出红线时拒绝降挡并提示。手动操作允许偏离弯道建议速度，但仍受车辆最大速度、转速及动力能力约束；终点会结束轨迹。这适用于构造怠速、滑行、急刹等调试场景，不是驾驶教学或车辆安全控制。

## 上报、坐标和存储

模型每 50ms 左右积分速度，每 100ms 左右同步位置和驾驶状态。同一速度用于推进路线并更新主界面速度，JT/T 808 位置汇报读取该实际速度（协议精度 0.1 km/h）。汇报开关和汇报间隔仍由现有通信设置控制，不因启用车辆模型而自动打开汇报。原始轨迹、模拟和上报坐标系保持一致，不添加新的隐式坐标转换。

两套地图的车辆设置互相独立，保存在主程序目录：

```text
Workspaces/Map/old/vehicle.json
Workspaces/Map/new/vehicle.json
```

保存采用原子写入。交通情景配置存于 `VehicleSimulationOptions.TrafficEvents`，保留原有 `RandomEventsEnabled` 总开关以读取旧配置。轨迹库快照和 `.ctsroute` 文件会带上车辆和全部交通设置，恢复轨迹时一并恢复。旧文件若只有随机事件总开关，则补齐新的默认情景配置；缺失的事件类型补默认值，非法参数拒绝应用。未包含车辆设置的旧轨迹按原有固定速度打开。运行中的挡位、油门和刹车指令不会存成下次自动执行的操作。`old/new` 使用各自独立文件，不共享记录或交通设置。

## 模型边界

这是面向协议测试的驾驶行为近似，不是经过车型标定的完整车辆物理系统。仅利用已有轨迹几何，随机事件须明确启用且标为模拟事件，不把它们当作真实路况；不计算真实离合器、发动机扭矩曲线、质量载荷、坡度和轮胎附着。路线的稀疏程度会影响弯道判断。小幅巡航波动采用可重复的平滑函数；随机事件测试可注入随机种子，便于回归。
