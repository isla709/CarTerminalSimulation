# 单地图响应式设计与实施计划

## 2026-10-20 方案修订

用户截图确认旧面板有灰色外壳、速度/坐标系错位。本轮已将操作面板改为 **Flutter 控件**，WebView 仅负责腾讯 GL 地图渲染；具体拆分、连续底图、字段规范、四平台合成和实施顺序见 [Flutter 原生面板方案](map-native-panel-plan.md)。

该方向已接入运行代码，当前采用无缝贴边 Flutter 面板，保留地图真实区域及 SDK 版权。旧 HTML 面板资源已移除；下文记录旧实现用于说明截图问题，新的设备矩阵仍待逐项验证。

## 范围与原则

Windows、Linux、Android、HarmonyOS 共用腾讯 GL 地图和一套业务桥。支持手机、平板、PC、可折叠设备及可调整窗口；按逻辑尺寸和可用空间布局，不能通过型号或固定屏幕像素判断。

地图只采用原 new 方案。2D/3D、搜索与联想、导航候选、绘制/单点、坐标切换、文件/历史、车辆配置、驾驶遥测和手动控制保留。旧地图的资源、服务、配置选择和回退不属于移植范围。

## 已停用的 HTML 过渡实现（历史记录）

| 可用空间 | 布局 | 关键行为 |
|---|---|---|
| 宽度小于 600，或宽度小于 900 的竖屏窗口 | 底部控制面板 | 默认高度上限 55%，编辑区滚动，开始/停止在滚动区外；收起后保留头部及动作 |
| 横屏且宽度至少 600、高度至多 500 | 紧凑侧栏 | 侧栏宽度取 360 与窗口宽度 46% 的较小值；简化头部，保留地图操作区 |
| 其他平板和桌面窗口 | 侧栏 | 宽度随窗口在 320–400 逻辑像素间变化；地图占剩余区域 |
| 宽度小于 380 | 窄屏重排 | 简化品牌区域，车辆及事件参数单列，文本允许换行 |
| 软键盘占用视口 | 编辑优先 | 跟随 VisualViewport 的高度/偏移；底部面板临时隐藏头部和模拟按钮，键盘关闭后恢复 |
| 竖屏模拟运行 | 驾驶摘要 | 摘要浮于地图；主动展开后覆盖为完整控制区，支持滚动踏板/挡位面板 |

- 地图容器预留控制面板占用的区域，路线拟合边距随容器尺寸变化；保留 SDK 版权区域。
- 安全区使用 `safe-area-inset-*`，宿主 SafeArea 与页面均以实际可用边界为准；支持窗口缩放和方向改变，不依赖启动时尺寸。
- 输入使用 16px 字号；触控环境主要按钮至少 44px 高。搜索联想采用文档流内列表，减少小屏和输入法遮挡。
- 弹窗头部/动作固定，正文独立滚动；历史、车辆参数和 14 类事件配置都允许长内容。
- 支持明暗主题、局部玻璃高光和轻量过渡；模糊关闭时使用实色，系统/应用减少动态效果时禁用动画。地图图层本身不套整屏模糊。

## 尚需完成

1. Flutter 操作面板及最小腾讯 GL 渲染器已接入，安卓截图已确认灰底外壳消失、速度/坐标系上下对齐及 SDK 归属可见；继续按上述矩阵覆盖键盘、连续调整窗口及其他设备手势。
2. 联调手机/平板手势、后台恢复、无障碍与高字体缩放；增加铰链/折痕空间信息桥接，必要时分区显示。
3. HarmonyOS 原生沉浸光感：原生导航/页签材质与 Flutter 合成，API 26 能力启用、API 17 实色回退。地图内容与原生系统栏协调，但不把 CSS 玻璃声明为原生光感。
4. 测量真实 GPU 下拖图、缩放、面板过渡、驾驶遥测和软键盘出现时的帧耗时、输入延迟及内存。根据设备能力关闭模糊；保留可操作性优先。
5. Windows/Linux 桌面和 Android/HarmonyOS 手机/平板分别给出运行证据；编译成功不替代真机布局或性能验收。
