# CTS Flutter 移植实施记录

更新于 2026-10-20。这是正在实施的完整移植，尚未完成全部功能和四平台验收。

## 已确定的目标

- 分支 `codex/terminal-simulation-flutter-port`；项目 `TerminalSimulation.Flutter`。
- Windows/Linux 桌面、Android/HarmonyOS 手机和平板；不建设浏览器版本或 Web TCP 代理。
- Flutter/Dart；鸿蒙 CPF-Flutter 3.41.9+ohos-1.0.2，提交 `62357a93d653bf844f730bb1f4b7cc9e2139d14e`。本机普通 Flutter 为 3.38.5，生产版本仍需统一并复核依赖锁定。
- 排除 CTS 动态插件系统、自动更新器和安装器；Flutter 编译进应用的原生适配器不属于动态插件系统。
- 地图只采用原 `new` 的腾讯 GL 方案，跨平台项目已移除旧框架、地图切换器及服务分支；地图布局详见 [响应式设计](map-responsive-design.md)。
- API 17 最低兼容，HarmonyOS 原生材质针对 API 26 能力启用。保留低版本回退。

## 已确认的继承兼容行为

原 CTS 的 JT808 2.7.8 库在 36 通道参数应答中将 `0x0077` 的 757 字节长度窄化为单字节 `245`；完整消息体为 976 字节。Dart 当前按原 CTS 字节保留此行为，不能将它描述为标准长度校验已通过。后续提供严格模式时需明确兼容策略，不能静默改变既有平台联调数据。
