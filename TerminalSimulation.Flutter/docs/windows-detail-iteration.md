# Windows 细节迭代（2026-10-20）

## 本轮修复

1. 地图模拟：`MaterialApp` 仅在主题/玻璃/减少动画设置变化时重建；连接头部独立观察连接状态。导航页保留状态，隐藏页及被工作台覆盖的页面停止随遥测重建。地图坐标只进入渲染队列，整个操作面板只在运行/准备状态切换时更新，驾驶摘要独立观察遥测。
2. 拖动地图时，JavaScript 先在本地暂停跟随再通知 Dart，避免异步往返期间争夺视角；滚轮也暂停跟随。车辆使用 100 ms 插值，只增量更新车辆标注，减少动画设置开启时直接更新。静态路线和起终点不随每次遥测重建。点更新依据 [腾讯 MultiMarker 官方接口](https://lbs.qq.com/webApi/javascriptGL/glDoc/glDocMarker) 的 `updateGeometries`。
3. 注册身份展开区域为浮动标签预留随文字缩放变化的上边距，保持多列/窄窗重排。
4. 鉴权码按用户要求明文显示，关闭自动纠错和输入建议，仍不写入普通设置或磁盘。
5. 工具页只保留 JT808 分析入口，进入独立全页工作台。包含与 WPF 相对应的六列表格、树状分组、原始 HEX、反转义字节偏移、位字段、筛选、详情、Ctrl/Shift 多行选择、Ctrl+C、完整 TSV/JSON 复制及快捷键。返回后再次进入保留本次会话输入、结果和模式。

## 稳定性与解析边界

- 解析在工作 isolate 中执行；输入变化、取消、清空和退出会使旧结果失效，任务串行，快速重复操作不会无限并发启动 isolate。输入限制 256 KiB 文本、64 KiB 单帧。表格与树状行按需创建，长字段完整值在详情中查看。
- 公共 JT808 编解码器验证边界、转义、校验、消息体长度及 BCD 手机号；结果表精确保留反转义帧的原始字节与偏移，位字段与父字段共享字节，不重复累计偏移。
- 当前字段解码覆盖注册/应答、鉴权、通用应答、参数、位置/附加项/状态位、批量位置、文本/透传及常用音视频信令等。加密数据不解密，分包不自动重组，未实现的消息体保留原始数据并显示提示。界面形态已对齐 WPF，**不表示覆盖 WPF 所依赖协议库的全部消息解码器**。
- 保留此前 Windows CEF GPU 描述符生命周期修复。本轮不改动 Android/HarmonyOS 原生宿主；移动端安排在阶段结束后验证。

## 本机记录

- Windows Debug 构建完成；Dart 静态分析无问题。本轮没有新增或运行自动化测试。
- 使用 Windows Computer Use 实际展开注册身份并滚动查看完整字段；进入独立报文分析工作台并解析内置 0x0200 示例，表格显示 28 个字段，树状切换正常。
- 运行两点自由绘制路线，进行地图拖动、面板滚动、恢复跟随和停止模拟。拖动后视角保留，模拟遥测继续更新；恢复跟随后车辆再次居中。
- 显式 `-DebugFrameTimings` 开关记录每 5 秒窗口的 Flutter UI 构建/栅格 P95 和 20 ms 事件循环探针延迟。默认关闭，Release 禁用，不记录凭据、坐标或报文。使用单调时钟；日志在 `bin/Debug/windows-detail-stdout.log`。
- 当前机器的短时 Debug 记录：稳定模拟窗口 UI 构建 P95 约 4.7–6.8 ms、栅格 P95 约 1.9–3.2 ms；大部分窗口事件循环延迟 P95 约 1.4–7.3 ms，也出现 20.13 ms 的窗口。启动窗口最大探针延迟曾达 841.52 ms，模拟启动窗口 65.10 ms，不能宣称全程无尖峰。无修改前的同条件基线，不提供改善百分比。
- Flutter 框架采样不包含 CEF 内部完整帧耗时，不能把每秒框架帧数当作地图 FPS。未进行所有显卡、复杂长路线、高倍率系统缩放或长稳验收。标准错误出现一条 Flutter Windows 无障碍 `Announce message viewId` 提示，未见本轮 Dart 异常或原黑屏的外部纹理错误，仍需后续跟踪无障碍引擎兼容性。
- 构建日志：`bin/Debug/windows-detail-iteration-build.log`（诊断版）与 `bin/Debug/windows-detail-final-build.log`（最终默认版）。当前工作区未提交。
