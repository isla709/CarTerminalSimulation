# 驾驶与交通情景移植

## 实现

`lib/core/vehicle_options.dart`、`vehicle_driver.dart`、`vehicle_events.dart`、`driving_route.dart` 对应原 CTS 的车辆参数、纵向驾驶控制、交通事件和路线速度包络。

- 保留小型自动挡、小型手动挡、电动车、手动卡车四种预设；手动、普通自动、CVT、DCT、单速五种变速箱；汽油、柴油、电动、混动四种动力类型。
- 参数范围、逐挡递减齿比、升降挡转速关系、空挡/换挡断动力、危险降挡保护、红线限制、油门/刹车与加加速度平滑按原逻辑移植。
- 相邻小弯合并为连续转弯，入弯提前减速，过弯心逐步释放速度限制；支持左右转差异、车辆能力、驾驶风格和终点平顺停车。
- 完整保留 14 类合成交通情景、独立机会时钟、概率/间隔/启用开关、路口放置条件、阶段时间和轮数。停车等待只在停稳后计时；手动接管清除交通等待，恢复自动不会继续旧事件。
- 路线使用前后速度均值积分位移，最大 50 ms 内部时间步。外部计时使用单调时钟，挂起恢复后的单次补算最多一秒，避免瞬移。
- AppModel 在后台 isolate 构建最多十万点的速度包络；启动/停止使用代次保护，过时准备结果不会启动定时器。车速同时驱动位移、遥测与 JT808 位置汇报。
- 地图 `vehicle_settings`、`vehicle_control` 已接通，车辆配置统一存储于 `map-vehicle.json`。地图收到完整预设/事件目录和实时遥测；轨迹文件页也显示速度、挡位、转速、踏板及进度。

这些是原 CTS 的行为近似模型与合成情景，不是实际交通信号或经过实车标定的物理参数。

## 对照证据

`tool/driving_oracle/DrivingOracle.csproj` 直接链接原项目四个公开驾驶源码文件，用轻量 DTO/接口代替 WPF 宿主。它不引用整个 WPF 工程、内部插件或地图凭据。生成：

```powershell
dotnet run --project tool/driving_oracle/DrivingOracle.csproj -- test/fixtures/driving-csharp.json
```

样本包括 6 组驾驶过程（覆盖所有变速箱、四种动力、手动操作及终点刹车）、14 类完整事件过程、左右转/稠密弯道/重复点 4 组路线。Dart 检查样本中的各遥测字段、阶段/轮次、完成时刻、距离、几何约束与朝向；数值容差为绝对 `1e-7`。

为消除运行库随机数算法差异，C# 和 Dart 对照均注入同一个固定随机流：浮点 `0.01`，整数取区间最小值。生产环境仍使用 Dart 随机数；不能据此声称相同整数 seed 会生成与 .NET 相同的交通序列。

补充回归覆盖真实转弯积分、空挡手动接管、异常踏板输入、取消异步准备、终点与挂起时间限制、车辆设置保存及跨地图文档恢复、地图手动控制与速度汇报一致性。以上数值对照和 80 项通过记录来自单地图调整前；本轮更新桥接回归源码以使用统一配置，未重新运行测试。原完整回归日志写入仓库 `bin/Debug/flutter-regression-driving.log`。
